# VPN: исключён из текущего задания

По уточнению пользователя 24 октября 2026 года собственная VPN-интеграция отменена. RainCode не устанавливает VPN-драйвер, не создаёт VPN-туннель, не выбирает провайдера и не меняет системные маршруты. Предыдущее исследование WireGuard не является активным TODO или обещанием реализации.

**VPN не обязателен для подключения к Tor.** Нельзя корректно показывать предупреждение «для Tor обязательно нужен VPN». Tor Project обычно не рекомендует сочетать VPN и Tor без достаточного понимания конфигурации: такая комбинация может ухудшить приватность. [Официальная рекомендация Tor Project](https://support.torproject.org/tor-browser/general/vpn-with-tor/).

Если пользователь самостоятельно включил системный VPN, браузер использует маршрутизацию ОС. Наличие VPN-адаптера не доказывает, что конкретный запрос, DNS и IPv6 проходят через него. RainCode не обещает дополнительную анонимность от такой комбинации. При критичной необходимости анонимности следует использовать официальный Tor Browser.

Tor Mode и Proxy Mode остаются разными реализованными режимами браузера. SOCKS5/Tor не создаёт системный VPN, а Network Kill Switch RainCode имеет область приложения и не считается системным firewall/VPN kill switch.

Асинхронный safeStorage в RainCode используется для proxy credentials. Он не означает наличие VPN-конфигураций или VPN-ключей. Windows DPAPI защищает хранимые данные от других учётных записей, но не гарантирует защиту от вредоносного процесса той же учётной записи. [Electron safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage).

Технический контекст исследования: официальный WireGuard Windows использует tunnel services; встраивание требует отдельного системного компонента, проверки подписи, лицензий и привилегированной установки. Эти действия **не выполняются** в RainCode в рамках текущего задания. [WireGuard enterprise documentation](https://git.zx2c4.com/wireguard-windows/about/docs/enterprise.md).
